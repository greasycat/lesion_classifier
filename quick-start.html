Quick start

1. Requirements​

  • Linux with Python 3.11 or 3.12 and uv. An NVIDIA GPU is recommended (CUDA 12.8 wheels); the CPU works too, at about 3 s per image.
  • The M-SYNTH images on disk (see step 3).

2. Set up the project​

From the project directory:

# Python environment
uv sync
# network trunk definition (GMIC, pinned commit)
git clone https://github.com/nyukat/GMIC third_party/GMIC
git -C third_party/GMIC checkout 594029e
# model weights: copy A1_centre.pt into models/, then check it
(cd models && sha256sum -c A1_centre.pt.sha256)

The weights file models/A1_centre.pt is not in git.

3. Point to the data​

config/datasets.yml says where M-SYNTH lives:

data_root: /data/1TB/breasts
datasets:
  msynth:
    root: msynth          # -> /data/1TB/breasts/msynth

Expected layout under the M-SYNTH root:

folderused for
images/ld<lesion density>/dose<dose>/r<radius>mm/<breast density>/<case>/image.pngthe mammograms
breast_masks/...breast masks (optional; computed on the fly if missing)
masks_binary/...true lesion masks (optional; only for outlines and on_lesion)

manifests/msynth/*.csv list the images with their parameters and splits (test.csv, test_p10.csv, ...).

4. Make heatmaps and boxes​

uv run python -m msynth_heatmap render --manifest manifests/msynth/test_p10.csv --view p10
uv run python -m msynth_heatmap topk   --manifest manifests/msynth/test_p10.csv --view p10 --k 3 --min-p 0.01

Results go to <M-SYNTH root>/heatmaps/A1d_p10/ and .../A1d_p10_top3/. Next: Heatmaps, Top-k places.

5. Interactive notebooks​

uv run --group notebook jupyter lab notebooks/
  • preview_heatmaps.ipynb: heatmaps with every visual setting.
  • topk_heatmaps.ipynb: pick images by breast density, lesion density, size and dose; top-k boxes.
