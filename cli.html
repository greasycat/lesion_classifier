CLI reference

uv run python -m msynth_heatmap {render,topk} [options]

Common options​

optiondefault
--images PATH ...image paths, relative to the M-SYNTH root or absolute (one of --images / --manifest)
--manifest CSVCSV with an image column, e.g. manifests/msynth/test.csv
--where col=value ...filter the manifest, e.g. lesion_present=1 dose_pct=20
--limit Nallfirst N images
--viewp10p05, p10, p20, p50, full: declared prevalence
--calibdensitydensity or pooled
--out DIR<M-SYNTH>/heatmaps/A1d_<view>output folder (A1_ for pooled; topk adds _top<k>)
--viz YAMLconfig/heatmap_viz.ymlvisual settings
--set key=value ...override visual settings
--deviceautocuda or cpu

topk only​

optiondefault
--k3number of places
--min-p0minimum probability
--sep-mm10minimum distance between places
--box-frac0.5box = region with p ≥ frac × peak p
--heatfullfull, boxes, none
--no-ranksoffhide rank numbers
--save-mapsoffalso write the maps
